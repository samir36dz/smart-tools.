بناء Smart Tools من الهاتف باستخدام GitHub Actions

1) أنشئ مستودعاً جديداً في GitHub باسم smart-tools.
2) اجعل المستودع Private في البداية.
3) ارفع محتويات مجلد Smart-Tools-Updated إلى جذر المستودع (لا ترفع ملف ZIP نفسه).
4) افتح تبويب Actions في المستودع وفعّل GitHub Actions إذا طلب منك ذلك.
5) افتح workflow باسم Build Smart Tools Android واضغط Run workflow.
6) انتظر حتى تنتهي المهمة بنجاح.
7) افتح نتيجة التشغيل ثم قسم Artifacts وحمّل smart-tools-android-build.
8) يحتوي الأرشيف على APK تجريبي وAAB إصدار غير موقّع. الـ AAB غير الموقّع ليس جاهزاً للرفع إلى Google Play؛ يجب توقيعه بمفتاح إصدار محفوظ بأمان قبل النشر.

ملاحظات:
- لا ترفع أي ملف .env أو مفتاح توقيع أو كلمة مرور إلى GitHub.
- لا تضع OPENAI_API_KEY داخل ملفات الويب أو المستودع.
- هذه workflow تبني نسخة Debug APK وRelease AAB غير موقّع فقط. لا تدمج AdMob تلقائياً.
- احتفظ بالمستودع Private أثناء التطوير، ويمكن جعل التطبيق عاماً لاحقاً إذا رغبت.
