SMART TOOLS 2.1 – خطوات تجهيز Android

مهم: هذه ملفات المصدر وتجهيز Capacitor، وليست ملف APK أو AAB جاهزاً. بناء Android يحتاج Node.js وAndroid SDK وبيئة بناء مناسبة (عادةً Android Studio على كمبيوتر).

1) احتفظ بنسخة احتياطية من مجلد المشروع.
2) على كمبيوتر، ثبّت Node.js LTS وAndroid Studio مع Android SDK.
3) افتح الطرفية داخل مجلد المشروع وشغّل: npm install
4) أضف منصة Android لأول مرة: npx cap add android
5) بعد أي تعديل على ملفات الويب شغّل: npx cap sync android
6) افتح المشروع: npx cap open android
7) اختبره على هاتف حقيقي، خصوصاً الكاميرا والروابط والرجوع والعمل دون اتصال.
8) من Android Studio أنشئ Signed Bundle / AAB باستخدام مفتاح توقيع محفوظ بأمان. لا تشارك ملف المفتاح أو كلمات مروره.

قبل النشر: يجب فحص إعدادات الشبكة والكاميرا، تفعيل سياسة الخصوصية الفعلية، تحديد تصنيف المحتوى والجمهور المستهدف، وتجهيز صفحة Data safety. AdMob غير مدمج حالياً، ومساعد AI يحتاج خادماً مستضافاً ومفتاح API محفوظاً على الخادم فقط.

معرّف التطبيق المقترح: com.smarttools.global. لا تغيّره بعد أول نشر عام دون سبب قوي.
